LogSightLATEST

A zero-cost, fully local log analysis platform that uses an LLM (Qwen3 4B via Ollama) to triage security logs. Upload logs through a web interface and LogSight parses, stores and enriches them, then presents findings on a SOAR-style dark dashboard.

  • FastAPI web app with log upload and a parse → ingest → enrich → detect pipeline that runs automatically after each upload.
  • SQLite schema with 8 tables, report views, batch tracking, dedup hashes and a MITRE ATT&CK lookup table, feeding 6 dashboard reports.
  • IP reputation engine querying VirusTotal, AbuseIPDB and AlienVault OTX, with a 24-hour cache and a consensus verdict.
  • Incident detector plus a Qwen3 narrator that writes plain-language incident summaries, verified by an automated test suite.
